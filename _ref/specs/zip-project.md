# ZIP project (ZZStudio-Complete-Website): implementation-reuse spec

Source: `WD/src_zip/ZZStudio-Complete-Website/` (WD = the scratch working directory).
Method: I read every file listed in the task. I also rendered `dist/` in a separate headless Chromium (Playwright from `WD/_tools/node_modules`; the in-app browser pane was not used) to measure layout and sample motion frame by frame.
- Scripts and screenshots: `WD/_tools/zipspec/` (`measure.cjs`, `motion.cjs`, `assets.py`, `measure.json`, `tables.md`, `shots/*.png`).
- Values marked "(measured)" come from that headless run at the stated viewport.
- Everything else is quoted from source CSS/JS.
- "(est.)" marks an estimate.

---

## 0. Key findings

1. **What the ZIP is.** It is a static, framework-free recreation of **zzstudio.design**, the portfolio of Abdul Mutakabar Ayaz / "ZZStudio".
   - It is built by a Python generator (`scripts/build.py`) with one vanilla JS file (`src/app.js`, 166 lines) and one CSS file (`src/styles.css`, 25 KB).
   - Output is `dist/`: 10 routes plus a root `404.html`, and 102 source assets / 304 WebP variants (33.5 MB).
   - **All project artwork, logos, portraits and copy belong to ZZStudio, its clients or a Framer template.** None of it is TESERACT's. Treat it as placeholder or dev data only.
2. **The "Studio page, second section" = the home page's project gallery** (`<main class="main-column home-gallery">`). Section 2 explains why.
3. **Motion is simple CSS transitions driven by class toggles.** There is no GSAP and no smooth-scroll library.
   - One shared easing: `--ease: cubic-bezier(.22,1,.36,1)`.
   - Image reveal is **scale 1.1 → 1 only** over 1300 ms inside `overflow:hidden`. There is no opacity or clip-path, and it fires once at IO threshold 0.04.
   - Hover effects: caption **whole-line roll** (500 ms) and image **scale 1 → 1.018** (1300 ms). Nav and CTA use a **per-letter roll** (520 ms, 12 ms stagger).
   - Page leave: black shade fades in over 220 ms, then navigation.
   - Text entrance: 850 ms, opacity 0 → 1 and translateY 24 px → 0.
4. **Missing features.** There is **no video anywhere** and **no "View Project" label, cursor or preview**. The only "view" is `aria-label="View {title}"` on the tile link. Those interactions must be designed fresh, for example from the Budarina reference.
5. **Critical bugs to avoid when porting:**
   - (a) `assets/geist-mono.woff2` is the **wrong Google-Fonts subset**: box-drawing glyphs, with only `A`, `Á`, `Ă` among letters. All mono UI text renders in the system monospace (Consolas/Courier), with a stray Geist Mono "A".
   - (b) The partner logos are `fill="#000"` on a #000 page, so they are invisible.
   - (c) `build.py` crashes on Windows with `UnicodeEncodeError`, because `write_text()` is called without `encoding="utf-8"`.
   - (d) The tablet `--panel:34%` rule is dead code because of cascade order.
   - (e) `sizes` attributes are wrong at 810–1199 px.
   - (f) The `mailto` email card has no accessible name.
   - Full list in section 15.

## 2. Which "Studio page / second section" is meant

**Decision: the home page (`dist/index.html`), section 2 = `<main id="main-content" class="main-column home-gallery">`, the vertical column of 10 full-bleed project tiles.** Secondary reference: the same pattern on case-study pages (`main.case-gallery`, 13 frames).

Justification:
- The whole site is "ZZStudio". Its home page is the Studio's main page, titled "Design & Development Agency — ZZStudio".
- The DOM of the home `<body>` is: skip-link, rail, header, **section 1 = `section.sidebar.home-sidebar`** (intro, CTA, logo ticker, service stack), then **section 2 = `main.home-gallery`**.
- On phones (<1200 px) the sidebar stacks above, so the gallery is also visually the second section.
- Every behaviour the user lists exists only in that gallery and its case-study pages: animation smoothness, scroll behaviour, project presentation, image reveals, project previews and "View Project" interactions. That means scroll-triggered image reveals, tile hover zoom, caption letter-roll, link to the case study and the page-leave shade.
- The alternative reading is the **profile page**, literally titled "Studio Profile". Its second section is `section.identity-section`: a 208 px-tall block with one `<h2>` ("AgenQ — The Identity") and one `<p>`. It has **no images, no motion and no projects**, so it cannot serve as a reference for any of the listed behaviours.
- Caveat: "video reveals" and "View Project" do not exist in the ZIP. The AUDIT also notes no `<video>` was found on the live zzstudio.design. Those two items must come from another reference.

### 4.4 Hover / focus state (tile)

```css
.reveal-image img{transform:scale(1);transition:transform 1.3s var(--ease);will-change:auto}
.project-tile:hover .in-view img{transform:scale(1.018)}
.roll{display:inline-block;position:relative;height:1.4em;line-height:1.4;overflow:hidden;vertical-align:middle}
.roll>span{display:block;white-space:nowrap;transition:transform .5s var(--ease)}
.roll>span+span{position:absolute;top:100%;left:0;color:inherit}
a:hover .roll>span, a:focus-visible .roll>span{transform:translateY(-100%)}
```

Behaviour:
- Hovering anywhere on a linked tile does two things:
  - It rolls **both** caption lines (title and category) up by one line. The second copy slides in from below, giving the same text, so it reads as a "flip". This takes 500 ms.
  - It zooms the image to **1.018×** over 1300 ms.
- **The date does not roll.**
- Measured: the caption line reached −15.39 px (= −100% of the 15.4 px line) within about 300 ms (ease-out). The image reached 1.018 after about 1.3 s.
- **Mouse-out** reverses both with the same durations.
- **`<article>` tiles** (no link) get the zoom but **not** the roll, because the selector requires `a:hover`.
- **There is no custom cursor**: just the default pointer on links.
- **There is no "View Project" pill, overlay, preview image or video, and no dimming of other tiles.**
- Focus: `:focus-visible{outline:2px solid #DEFC3E;outline-offset:5px}`. Focus also triggers the roll. Because of `overflow:hidden` on the tile, an outline offset of 5 px is drawn outside the tile and remains visible.

### 4.5 Image reveal (scroll-triggered)

JS (`revealImages`, exact):

```js
const frames = document.querySelectorAll('.reveal-image');
if (reduced.matches || !('IntersectionObserver' in window)) { frames.forEach(f => f.classList.add('in-view')); return; }
document.documentElement.classList.add('js-motion');
const observer = new IntersectionObserver(entries => {
  entries.forEach(entry => { if (!entry.isIntersecting) return;
    entry.target.classList.add('in-view'); observer.unobserve(entry.target); });
}, { threshold: 0.04 });            // no rootMargin
frames.forEach(f => observer.observe(f));
```

CSS:

```css
.reveal-image{overflow:hidden}
.js-motion .reveal-image:not(.in-view) img{transform:scale(1.1)}
/* in-view -> scale(1) via the 1.3s var(--ease) transition */
```

Behaviour:
- Pre-state: image at **scale 1.1**, clipped by its frame. Opacity is 1, and there is no clip-path, mask, blur or translate.
- Trigger: when **4%** of the frame intersects the viewport. It fires once, then unobserves.
- Animation: scale **1.1 → 1.0** over **1300 ms**, easing `cubic-bezier(.22,1,.36,1)`, with no delay and no stagger.
- Measured above the fold at 1440: scale 1.1 at the first frame. The reveal began at about 590 ms after navigation, read 1.0943 at 611 ms, 1.0085 at 1105 ms and 1.00002 at 1755 ms.
- Measured on scroll (tile 4): 1.1 until intersecting, then 1.063 about 400 ms later and 1.0006 about 1.2 s after that.
- The tile background is `#111` (case frames `#0b0b0b`). Because images are `loading="lazy"` with no fade, a slow image can **pop in** mid-scale.
- The same `.reveal-image` class is used on case-study frames, profile editorial, offer images and team cards.

### 4.6 Navigation from a tile (page-leave transition)

```js
document.addEventListener('click', e => {
  const link = e.target.closest('a[href]');
  if (!link || e.defaultPrevented || e.button !== 0 || e.metaKey || e.ctrlKey || e.shiftKey || e.altKey || link.target || link.hasAttribute('download')) return;
  const next = new URL(link.href, location.href);
  if (!['http:','https:','file:'].includes(next.protocol) || next.origin !== location.origin || next.hash || next.pathname === location.pathname || reduced.matches) return;
  e.preventDefault(); document.body.classList.add('is-leaving');
  setTimeout(() => location.assign(next.href), 220);
});
window.addEventListener('pageshow', () => document.body.classList.remove('is-leaving'));   // bfcache restore
```

```css
.page-shade{position:fixed;inset:0;z-index:50;pointer-events:none;background:#000;opacity:0;transition:opacity .22s ease}
.is-leaving .page-shade{opacity:1}
.is-leaving .main-column{transition:opacity .2s;opacity:.1}
```

- Measured: shade opacity 0.19 at 65 ms, 0.75 at 127 ms, 0.93 at 187 ms and 1.0 at about 250 ms. `.main-column` opacity reached 0.1 at about 200 ms. Unload happened at about 220 ms.
- **There is no enter transition on the next page**: the new page paints directly. Only its `.entrance` elements animate (sidebar title and CTA).
- External tiles (`target=_blank`) skip the transition.

## 6. Reduced motion

**CSS** (`@media (prefers-reduced-motion: reduce)`):

```css
html{scroll-behavior:auto}
*,*::before,*::after{animation-duration:.01ms!important;animation-iteration-count:1!important;transition-duration:.01ms!important;transition-delay:0s!important}
.js-motion .reveal-image:not(.in-view) img{transform:none}
.logo-track{animation:none}
.page-shade{display:none}
```

**JS:**
- `revealImages` marks all frames `in-view` and never adds `js-motion`.
- `letterRolls` is skipped. The whole-line roll still swaps text, but instantly.
- The service stack starts paused, and a `change` listener re-evaluates.
- `pageTransitions` returns early, so navigation is immediate.

`reduced.matches` is read once at load, except for the service stack.

**Font file problem.**
- `geist.woff2` (29,400 B) is Google's **latin** subset. It has 225 code points and lacks ↗ (U+2197), Ⅱ (U+2161), ✉, ● and ▶, which fall back to Arial or system fonts.
- `geist-mono.woff2` (5,812 B) is the **box-drawing subset**: U+2500–259F plus space, A, Á and Ă. **Every mono label therefore renders in the system monospace**, with only "A" in Geist Mono. This is visible in `shots/mono_zoom.png`.
- For the rebuild, use the full Geist / Geist Mono variable fonts (e.g. the `geist` npm package or the Vercel release), or the correct latin subset.

## 14. Reusable code

### 14.1 `picture()`: responsive `<img>` from the manifest (build.py L27–34)

```python
def picture(name, alt, base, *, sizes='70vw', eager=False, cls=''):
    a = ASSETS[name]
    if 'file' in a:   # vector / font: plain img
        return f'<img src="{base}{a["file"]}" alt="{E(alt)}" class="{cls}" loading="lazy" decoding="async">'
    variants = a['variants']
    default = next((v for v in variants if v['width'] >= 1280), variants[-1])
    srcset = ', '.join(f'{base}{v["file"]} {v["width"]}w' for v in variants)
    return (f'<img class="{cls}" src="{base}{default["file"]}" srcset="{srcset}" sizes="{sizes}" '
            f'width="{a["native_width"]}" height="{a["native_height"]}" alt="{E(alt)}" '
            f'loading="{"eager" if eager else "lazy"}" decoding="async" {"fetchpriority=high" if eager else ""}>')
```

Reuse as is, with these fixes:
- Pass correct `sizes` per breakpoint, e.g. home tiles `(min-width:1920px) 80vw, (min-width:1200px) 70vw, 100vw`.
- Add width/height for SVGs.
- Quote `fetchpriority="high"`.
- Drop the empty `class=""`.
- Optionally emit `<picture>` with an AVIF `<source>`.

Manifest schema per raster: `{url, name, vector:false, source_page, native_width, native_height, sha256, variants:[{file,width,height,bytes}]}`.

### 14.2 `roll()` and `cta()` (L36–40) plus JS `letterRolls()`

```python
def roll(text): return f'<span class="roll" aria-hidden="true"><span>{E(text)}</span><span>{E(text)}</span></span>'
def cta(base, text='Book a 30-min call', url=None, cls=''):
    return f'<a class="cta {cls}" href="{E(url or BOOK)}" aria-label="{E(text)}" {"target=_blank rel=noopener" if (url or BOOK).startswith("http") else ""}><i class="status-dot" aria-hidden="true"></i>{roll(text)}</a>'
```

- The pattern is: duplicated text, an `aria-hidden` visual layer, and an accessible name on the parent.
- Keep it, but always put the `aria-label` on the focusable element. The email card currently has no name.

## 15. Problems and bugs found

1. **Geist Mono file is the wrong subset.** `assets/geist-mono.woff2` covers only U+2500–259F plus A/Á/Ă. All mono UI text falls back to the system monospace, with mixed "A" glyphs (`shots/mono_zoom.png`).
2. **Geist (latin subset) lacks ↗ Ⅱ ✉ ● ▶.** These use fallback fonts.
3. **build.py is Windows-unsafe.** `write_text()`/`read_text()` have no `encoding="utf-8"`, giving `UnicodeEncodeError: 'Ⅱ'` (Ⅱ) on cp1252. Run with `python -X utf8` or patch. check.py has the same pattern on reads.
4. **Partner logos are invisible** on the profile page (`fill="#000"` SVGs on `#000`, no filter or invert). Verified in a screenshot.
5. **Service icons are nearly invisible** (stroke `#292D32` on `#111`).
6. **Dead tablet panel rule.** `@media(min-width:810px) and (max-width:1199px){:root{--panel:34%}…}` is overridden by the later `@media(max-width:1199px){:root{--panel:100%}}`, so tablet is a stacked single column. The tablet `h1 27px` and `.project-information h1 27px` rules are dead in the same way.
7. **Wrong `sizes` at 810–1199.** Home says 70vw (actual 100vw); case pages say 35vw/70vw (actual about 50vw/100vw). This picks under-resolution variants on tablets.
8. **Tablet overlap.** The service-stack controls overlap the "WHAT WE ARE BEST AT" label (controls `top:0; right:0` on a 260 px stack; see `shots/home_1024.png`).
9. **Reveal can pop in.** `js-motion` is added by a deferred script, so on slow loads images may first paint at scale 1 and then animate 1→1.1→1. There is also no opacity fade, so lazy images pop in mid-reveal.
   - Fix: add the class in an inline `<head>` script.
   - Fix: fade or decode-gate the reveal (`img.decode()`).
10. **No accessible name on the email card.** `a.email-card` has only aria-hidden children.
11. **Caption semantics.** `aria-label` on a generic `<span class="project-category">` is not reliably announced, and the tile's `aria-label="View …"` overrides the date and category. Screen readers hear only "View HOCL LABS".
12. **Duplicate team image.** Noah Grant reuses profile-19 (the Nickolas Park photo); `page-assets.json` itself lists duplicates.
13. **Profile page overlaps the rail.** `.profile-content{padding:0 40px}` ignores the fixed 52 px rail, so content at x=40 sits under the rail. On desktop profile the nav and rail are `background:transparent`, so scrolled content runs behind the HOME/CONTACT links (est. visual issue).
14. **No footer on desktop** home and case pages (it is `.mobile-only`). Desktop users never reach the contact or footer from those pages except via the nav.
15. **Article tiles behave inconsistently** (SunnaKids, Web Design). They zoom on hover but have no roll and no link. There is no "coming soon" affordance.
16. **No enter transition** after the 220 ms leave-shade, so the next page cuts in. `pageshow` only clears `is-leaving` for bfcache.
17. **Service-stack opacity mismatch.** CSS fallback opacities (.55/.25) differ from JS (.48/.23).
18. **Indexing is blocked.** Every page is `noindex,nofollow` and robots.txt is `Disallow: /`. No OG or canonical tags.
19. **Tafuta frame 13 is the home cover** (home-08) repeated.
20. **Low-resolution case images.** Aesthetic Origins frames 06, 07, 08, 09 and 12 are 2000×1600, and frames 06, 07 and 12 run full width.
21. **SVGs lack `viewBox`.** Fine in Chrome `<img>`, but brittle if inlined or used as CSS masks.
22. **Inconsistent date strings** ("MAR . 2025", "JULY 2025") and a non-chronological project order.

### C. The "View Project" cursor has no source; document what the build does
- **No source.** §16 says to "take it from the Budarina reference". **The reference has no such interaction**: ref-hero-nav covers the whole hero and gallery, and there is no cursor and no hover label.
